# Q5 — Multimodal Text-and-Image Assistant

Implementation file: `multimodal.py`.

**Features:** text prompt plus image upload, BLIP image captioning, optional Tesseract OCR, evidence validation, and uncertainty-aware output. Run via root app → **Q5 · Multimodal assistant**.

Install the Tesseract executable separately if OCR is required. This prototype is limited to caption/OCR-derived evidence and is not a general medical or safety vision system. Do not upload confidential or identifiable images.
