# Q6 — Multilingual Conversational Assistant

Implementation file: `multilingual.py`.

**Languages:** English, Hindi, Tamil, and Spanish. The module detects language, translates through English using NLLB-200, maintains recent conversation context in the Streamlit session, and translates responses back to the detected language.

Run via root app → **Q6 · Multilingual assistant**. The first use downloads a large open-source translation model. Mixed-language and short ambiguous messages may require clarification; verify translation quality before demonstration.
