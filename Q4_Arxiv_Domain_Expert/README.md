# Q4 — arXiv Domain Expert Chatbot

Implementation file: `arxiv_expert.py`.

**Dataset:** https://www.kaggle.com/datasets/Cornell-University/arxiv

Download the dataset from Kaggle and upload its CSV in the root Streamlit application under **Q4 · Research paper expert**. The app filters computer-science categories, searches titles/abstracts, summarizes abstracts, supports optional local Ollama explanations, and creates a concept graph.

Optional local LLM setup: install Ollama, run `ollama pull llama3.2`, and ensure the Ollama service is running. The full Kaggle dataset is not included in this repository.
